## 1. 摘要

本文针对 Tenth AI 原生语言编译期 HIR shape 约束求解的复杂度下界进行严格化分析。我们将跨函数 shape 求解形式化为线性等式约束系统在非负整数上的可满足性问题，通过松弛变量技巧将其与 0-1 整数规划相互归约，证明该问题 NP 完全（定理 B2b 的严格双向论证）。这一结论直接解释了 Tenth 项目护城河 B（Shape 代数求解器）从 ⭐⭐⭐⭐⭐ 降级为 ⭐⭐⭐ 的战略决策：编译期成本不可控与 Tenth 自举 ~0.2s 的核心保证存在结构性冲突。在 NP 完全性下界之外，本文进一步对 `tenth/std/nn/` 标准库的 shape 约束实例做实证分析，提出两个易解子类猜想：（C1）实际约束矩阵具有 total unimodularity 性质，可使整数规划多项式可解；（C2）二元等式约束系统在非负整数上可归约到 union-find，多项式可解。两个猜想均明确标注为未完成证明的开放问题。本文的工程结论是：Tenth 实际 shape 约束的精确复杂度可能远优于一般 NP 完全下界，但这一"乐观边界"目前仅为猜想，故护城河 B 的降级决策在理论层面是稳健的。

**关键词**：shape 约束求解、NP 完全性、松弛变量归约、0-1 整数规划、total unimodularity、union-find、编译期静态分析、AI 原生语言

## 2. 引言

### 2.1 AI 原生语言对编译期 shape 检查的需求

深度学习开发的工程痛点高度集中于 shape 推理：PyTorch 在 shape mismatch 时仅给出局部报错（如 `mat1 and mat2 shapes cannot be multiplied (3x8 and 4x8)`），开发者需自行沿栈回溯定位根因；JAX 的 `check_shading` 关注 sharding 而非代数 shape 推理。Tenth 作为 AI 原生编译型语言，将 shape 作为类型系统的组成部分（`Tensor[f64, M, K]` 中的 `M, K` 即 shape 变量），使得编译期 shape 检查成为可行的工程目标。

Tenth 已实现的护城河 A（Autograd 反向 Shape 静态验证）与护城河 D（编译期内存/算力预估）证明了"shape 作为类型"的工程价值：前者消除了 autodiff.rs 中的 5 处 silent squeeze 隐患，后者在编译期对 ≥1GB tensor 与 ≥1 GFLOP matmul 发 warning（详见 `tenth/src/hir/lower/types.rs::emit_memory_estimate`、`emit_matmul_flop_estimate`）。这两个方向均在多项式时间内完成，未引入复杂度风险。

### 2.2 跨函数 shape 求解的工程重要性

护城河 B（Shape 代数求解器）的目标更进一步：在跨函数边界上做 shape 约束的代数求解。典型场景如 `tenth/std/nn/linear.th`：

```tenth
fn linear(x: Tensor[f64, M, K], w: Tensor[f64, N, K], b: Tensor[f64, N]) -> Tensor[f64, M, N] {
    x.matmul(w.transpose()) + b
}
```

其中 `M, K, N` 是符号维度。编译期验证此函数签名的合法性需要建立约束：
- `matmul` 内侧维度相等：`K = K`（恒真）
- `transpose` 后 shape 反转：`w` 经 transpose 变为 `[K, N]`
- 广播加法兼容：`[M, N] + [N]` 广播为 `[M, N]`（要求 `N` 与 `N` 相等，恒真）

这些都是**等式约束**。当函数体内出现 `reshape(M*N)` 或 `flatten()` 时，约束变为**线性乘积等式** `d_1 · d_2 = d_3 · d_4`（reshape 元素守恒），这本质上是整数规划问题。跨函数传播进一步将多个函数的局部约束连接为全局约束系统，求解难度急剧上升。

### 2.3 研究问题与贡献

本文聚焦三个研究问题：

- **RQ1**：HIR shape 约束求解（限定为线性等式、非负整数域）的复杂度下界是什么？
- **RQ2**：这一下界如何解释护城河 B 的战略降级？
- **RQ3**：Tenth 实际 shape 约束（如 `tenth/std/nn/`）是否属于 NP 完全问题的易解子类？

本文的贡献：

1. **严格双向归约**（§6）：给出定理 B2b 的完整双向论证（NP 成员 + NP 困难），修正 §5 草稿中归约方向的单边性问题。

## 3. 背景与相关工作

### 3.1 类型约束求解的复杂度

**Hindley-Milner 类型推断**（HM）是函数式语言的基石，其复杂度特性已有定论：
- **ML 限制下的 HM**：W 算法在 $O(n^2)$ 时间内可解（虽然实际工程实现接近线性）
- **一般 HM 类型推断**：Damas-Milner 类型推断是 DEXPTIME 完全的（Mairson 1990）
- **Type class 约束求解**（Haskell GHC）：等价于 Horn 子句求解，半可判定

Tenth 的 shape 约束与 HM 类型约束的本质差异在于：
- HM 约束是**项等式**（unification），解空间是项代数
- Tenth shape 约束是**整数等式**（线性算术），解空间是 $\mathbb{N}^k$

这两类约束的复杂度特性不同。HM 在项代数上的 unification 是多项式可解的（Robinson 算法 $O(n^2)$），但整数线性等式约束在非负整数上是 NP 完全的（本文定理 B2b）。这意味着 Tenth 的 shape 检查比 Haskell 的类型检查在复杂度上更困难——这是"shape 作为类型"策略的内在代价。

### 3.2 整数规划复杂度理论

整数规划（Integer Programming, IP）的复杂度理论是本文的基础：

- **0-1 整数规划（0-1 IP）**：给定 $A \in \mathbb{Z}^{n \times k}$, $b \in \mathbb{Z}^n$，问是否存在 $x \in \{0,1\}^k$ 使 $Ax = b$？Karp (1972) 证明 0-1 IP 是 NP 完全的。
- **一般整数规划（IP）**：变量取值域为 $\mathbb{N}$，由 Karp 归约可证 NP 完全。
- **线性规划（LP）**：变量取值域为 $\mathbb{R}_{\geq 0}$，由 Khachiyan (1979) 椭球法证明多项式可解。
- **整数线性等式约束（IE）**：变量取值域为 $\mathbb{Z}$（含负），多项式可解（高斯消元）。
- **非负整数线性等式约束（NIE）**：变量取值域为 $\mathbb{N}$，**NP 完全**（本文定理 B2b）。

**Total Unimodularity（TU）** 是 IP 易解子类的核心概念。矩阵 $A$ 是 TU 的当且仅当其每个方子矩阵的行列式取值于 $\{0, \pm 1\}$。若 $A$ 是 TU 且 $b$ 是整数向量，则 IP 的 LP 松弛自动有整数解（Hoffman-Kruskal 定理），故 IP 多项式可解。TU 矩阵的典型例子：
- 完全幺模矩阵：网络流问题的节点-边关联矩阵
- 区间矩阵：每列连续非零元的矩阵
- Ghouila-Houri 条件：每行可二染色使列和取值于 $\{0, \pm 1\}$

### 3.3 NumPy/JAX 的 shape 推断策略

NumPy 与 JAX 的 shape 推断策略可作为对照：

- **NumPy**：完全运行时 shape 推断。每个算子在执行时检查输入 shape 兼容性，不匹配即抛 `ValueError`。无编译期 shape 分析。
- **JAX**：使用 `ShapedArray` 抽象值做 trace 期 shape 推断。`jax.core.check_shading` 检查 sharding 兼容性，但 shape 推断本身是单遍 trace（多项式时间），不做约束求解。JAX 的 `shape` 信息一旦在 trace 中确定就不再变化，不支持符号维度间的代数关系。
- **PyTorch `torch.compile`**：使用 symbolic shapes 做动态 shape 特化，但在运行时（Inductor 阶段）做约束求解，不进入编译主路径。

Tenth 的护城河 B 试图在编译期做更深的约束求解，这是与上述系统的本质差异，也是复杂度风险的来源。

## 4. Shape 约束系统的形式化

### 4.1 约束语言定义

**定义 4.1（Shape 变量）**：HIR 中的 shape 变量是符号 $d_1, d_2, \ldots, d_k$，取值域为 $\mathbb{N} = \{0, 1, 2, \ldots\}$。在 Tenth 实现中，对应 `Dim` 枚举的 `Known(n)` 与 `Symbol(s)` 变体（见 `tenth/src/hir/types.rs`）。`Dim::Any` 表示"未知维度"，不参与约束求解（视为自由变量）。

**定义 4.2（线性等式约束）**：线性等式约束是形如
$$a_1 d_1 + a_2 d_2 + \cdots + a_k d_k = c$$
的等式，其中 $a_i \in \mathbb{Z}$ 为整数系数，$c \in \mathbb{Z}$ 为整数常数，$d_i$ 为 shape 变量。

**注 4.1**：在 Tenth 实现中，线性等式约束来自：
- `matmul` 内侧维度匹配：$d_{lk} = d_{rk}$（系数 $a_l = 1, a_r = -1, c = 0$）
- `reshape` 元素守恒（受限子集）：$d_1 + d_2 + \cdots = c$（仅当所有 $d_i$ 已知时才检查，不建立符号方程）
- 跨函数参数 shape 一致：$d_{\text{caller}} = d_{\text{callee}}$

**定义 4.3（HIR Shape 约束系统）**：程序 $P$ 的 HIR shape 约束系统 $\Sigma(P)$ 是从 HIR 推导出的所有 shape 约束的合取式：
$$\Sigma(P) = \bigwedge_{i=1}^{n} \left( \sum_{j=1}^{k} a_{ij} d_j = c_i \right)$$

约束来源包括：
1. **函数签名约束**：参数 shape 与返回 shape 的关系
2. **算子内部约束**：由 `check_method_shape`、`check_binary_shape_compat` 生成（见 `tenth/src/hir/lower/types.rs:676`、`646`）
3. **跨函数传播**：函数调用处参数 shape 与签名一致（由 `merge_return_shape` 处理，见 `types.rs:496`）

**定义 4.4（约束可满足性）**：$\Sigma(P)$ 是可满足的，当且仅当存在赋值 $\sigma: \{d_j\} \to \mathbb{N}$ 使所有约束成立。记为 $\Sigma(P) \models \sigma$。

**定义 4.5（NIE 问题）**：非负整数线性等式约束可满足性问题（NIE）定义为：

> **输入**：矩阵 $A \in \mathbb{Z}^{n \times k}$，向量 $b \in \mathbb{Z}^n$
> **问**：是否存在 $x \in \mathbb{N}^k$ 使 $Ax = b$？

### 4.2 跨函数约束的来源

跨函数 shape 约束主要来自三个机制：

**机制 1：函数签名传播**。当函数 $f$ 声明 `fn f(x: Tensor[f64, M, K]) -> Tensor[f64, M, N]`，调用处 `f(y)`（其中 $y$ 的 shape 为 $[M', K']$）会生成约束 $M = M' \wedge K = K'$。返回值 shape $[M, N]$ 在调用处被使用时进一步传播。

**机制 2：算子内部约束的跨函数累积**。函数体内的 `matmul`、`reshape` 等算子生成的局部约束，在内联后变为全局约束。例如 `linear` 函数体内的 `x.matmul(w.transpose())` 生成约束 $K_{\text{lhs}} = K_{\text{rhs}}$（其中 $K_{\text{lhs}}$ 来自 $x$ 的第二维，$K_{\text{rhs}}$ 来自 $w$ 的第二维，因 `transpose` 反转）。

**机制 3：递归调用的不动点约束**。若 $f$ 递归调用自身，则 $f$ 的返回 shape 与递归调用的返回 shape 必须相等，生成不动点约束 $d_{\text{ret}} = d_{\text{recursive\_call\_ret}}$。这类约束在含递归时可能不可判定（`形式化分析理论可行性论证.md` 定理 B1）。

### 4.3 松弛变量技巧的数学构造

**核心思想**：松弛变量技巧将"变量取值域为 $\{0, 1\}$"的 0/1 限制转化为"变量取值域为 $\mathbb{N}$ 但有等式约束"的形式。这是整数规划理论中的标准工具（Schrijver 1986, §18）。

**构造 4.1（0/1 编码）**：对每个 0-1 变量 $x_i \in \{0, 1\}$，引入两个非负整数变量 $d_i, s_i \in \mathbb{N}$ 与一个等式约束：
$$d_i + s_i = 1$$

**引理 4.1（0/1 编码正确性）**：约束 $d_i + s_i = 1$ 在 $d_i, s_i \in \mathbb{N}$ 下当且仅当 $d_i \in \{0, 1\}$（且 $s_i = 1 - d_i$）。

**证明**：
- （$\Leftarrow$）若 $d_i \in \{0, 1\}$，取 $s_i = 1 - d_i$，则 $s_i \in \{0, 1\} \subseteq \mathbb{N}$，$d_i + s_i = 1$ 成立。
- （$\Rightarrow$）若 $d_i + s_i = 1$ 且 $d_i, s_i \in \mathbb{N}$，则 $d_i \geq 0$ 且 $s_i \geq 0$。若 $d_i \geq 2$，则 $s_i = 1 - d_i \leq -1 < 0$，与 $s_i \in \mathbb{N}$ 矛盾。故 $d_i \leq 1$。结合 $d_i \geq 0$ 得 $d_i \in \{0, 1\}$。$\square$

**直观解释**：$s_i$ 是"松弛变量"，吸收 $d_i$ 不取的值。当 $d_i = 0$ 时 $s_i = 1$；当 $d_i = 1$ 时 $s_i = 0$。这一构造将"离散选择"转化为"等式约束"，使原 0-1 IP 实例可改写为纯等式形式。

## 5. 主定理与证明

### 5.1 定理 B2a：线性约束在整数（含负）上多项式可解

**定理 B2a**：限定约束为线性等式 $\sum_j a_{ij} d_j = c_i$（$a_{ij}, c_i \in \mathbb{Z}$），变量取值域为 $\mathbb{Z}$（含负整数），NIE 问题（改记为 IE，Integer Equality）是多项式可解的，时间复杂度 $O(n^2 k)$。

**证明**：IE 等价于线性方程组的相容性判定，可用高斯消元法求解。

**算法**：
1. 将约束系统表示为增广矩阵 $[A | b]$，$A$ 为 $n \times k$ 系数矩阵，$b$ 为 $n \times 1$ 常数向量。
2. 对 $[A | b]$ 做高斯消元，化为行最简形（RREF）。
3. 检查 RREF：
   - 若出现 $[0 \, 0 \, \cdots \, 0 \, | \, c]$ 且 $c \neq 0$，则不相容（无解）
   - 否则相容（有解），且解可在 $\mathbb{Z}$ 上构造

**复杂度分析**：
- 高斯消元的每行消元需 $O(k)$ 次基本运算（消去一个主元）
- 共 $n$ 行，每行需与最多 $n$ 行相减
- 总复杂度 $O(n^2 k)$

**正确性**：高斯消元保持方程组的解集不变（行变换是同解变换）。RREF 的相容性判定是线性代数基本结果（参见 Strang 1988）。$\square$

**注 5.1**：B2a 的多项式可解性依赖变量可取负值。当变量限制为 $\mathbb{N}$ 时，高斯消元得到的整数解可能为负，不满足约束。这正是 B2b 的 NP 完全性来源。

### 5.2 定理 B2b：线性约束在非负整数上 NP 完全

**定理 B2b**：限定约束为线性等式 $\sum_j a_{ij} d_j = c_i$（$a_{ij}, c_i \in \mathbb{Z}$），变量取值域为 $\mathbb{N}$（非负整数），NIE 问题是 NP 完全的。

**证明结构**：分两部分论证。

#### 5.2.1 NP 成员

**引理 5.1（NIE ∈ NP）**：NIE 在 NP 中。

**证明**：给定证书 $\sigma: \{d_j\} \to \mathbb{N}$，可在多项式时间内验证所有约束是否成立：
- 每个约束 $\sum_j a_{ij} d_j = c_i$ 的验证：$O(k)$ 次乘法与 $O(k)$ 次加法，总 $O(k)$
- 共 $n$ 个约束，总验证时间 $O(nk)$

**证书的多项式长度**：需证 $\sigma(d_j)$ 的位长度多项式有界于输入规模。设输入系数 $a_{ij}, c_i$ 的最大位长度为 $L$。

考虑 NIE 实例的最小解（若存在）。由整数规划理论（Schrijver 1986, Corollary 10.2a），若 NIE 有解，则存在解 $x^*$ 使每个 $x^*_j$ 的位长度 $\leq O(kL \log(kL))$。具体地：
- 解空间是 $\mathbb{Z}^k$ 中的仿射子空间（由 $Ax = b$ 定义），其维数 $r \leq k$
- 解空间在 $\mathbb{N}^k$ 中的极点（vertex）由 $k - r$ 个紧约束（$d_j = 0$）确定
- 极点的各分量由 Cramer 法则确定，行列式展开的位长度 $\leq O(r \log r + rL) = O(k \log k + kL)$

故证书位长度多项式有界于输入规模 $O(nkL)$。结合验证时间 $O(nk)$，NIE ∈ NP。$\square$

#### 5.2.2 NP 困难（归约自 0-1 IP）

**引理 5.2（NIE 是 NP 困难的）**：NIE 是 NP 困难的，通过从 0-1 IP 多项式归约。

**归约来源**：0-1 整数规划（0-1 IP），定义为：

> **输入**：$A \in \mathbb{Z}^{n \times k}$, $b \in \mathbb{Z}^n$
> **问**：是否存在 $x \in \{0, 1\}^k$ 使 $Ax = b$？

0-1 IP 已由 Karp (1972) 证明 NP 完全。

**归约构造**：对 0-1 IP 实例 $(A, b)$，构造 NIE 实例 $(A', b')$ 如下：

1. **变量集扩展**：原 0-1 变量 $x_1, \ldots, x_k$ 替换为非负整数变量 $d_1, \ldots, d_k$；为每个 $d_i$ 引入松弛变量 $s_i \in \mathbb{N}$。新变量集为 $\{d_1, \ldots, d_k, s_1, \ldots, s_k\}$，共 $2k$ 个，全部取值于 $\mathbb{N}$。

2. **0/1 编码约束**：对每个 $i \in \{1, \ldots, k\}$，添加等式约束
$$d_i + s_i = 1$$
共 $k$ 个约束，强制 $d_i \in \{0, 1\}$（由引理 4.1）。

3. **原约束迁移**：原 0-1 IP 约束 $Ax = b$ 中的 $x_i$ 替换为 $d_i$，得
$$\sum_j A_{ij} d_j = b_i, \quad i = 1, \ldots, n$$
共 $n$ 个约束。

4. **构造的 NIE 实例**：
$$A' = \begin{pmatrix} I_k & I_k \\ A & 0_{n \times k} \end{pmatrix}, \quad b' = \begin{pmatrix} \mathbf{1}_k \\ b \end{pmatrix}$$
其中 $I_k$ 是 $k \times k$ 单位矩阵，$\mathbf{1}_k$ 是 $k$ 维全 1 向量，$0_{n \times k}$ 是 $n \times k$ 零矩阵。

**归约的多项式性**：
- 新变量数 $2k$，原变量数 $k$，多项式放大
- 新约束数 $n + k$，原约束数 $n$，多项式放大
- 系数取值于 $\{0, \pm 1\} \cup \{A_{ij}\}$，位长度不增
- 构造可在 $O(nk)$ 时间内完成

故归约是多项式时间归约。

#### 5.2.3 双向正确性论证

**引理 5.3（正向：0-1 IP 有解 ⇒ NIE 有解）**：若 0-1 IP 实例 $(A, b)$ 有解 $x^* \in \{0, 1\}^k$ 使 $Ax^* = b$，则构造的 NIE 实例 $(A', b')$ 有解 $(d^*, s^*) \in \mathbb{N}^{2k}$ 使 $A'(d^*, s^*)^T = b'$。

**证明**：取 $d^* = x^*$（即 $d^*_i = x^*_i \in \{0, 1\}$），取 $s^*_i = 1 - x^*_i \in \{0, 1\} \subseteq \mathbb{N}$。

验证 0/1 编码约束：
$$d^*_i + s^*_i = x^*_i + (1 - x^*_i) = 1 = b'_i \quad \text{对前 } k \text{ 个约束}$$

验证原约束迁移：
$$\sum_j A_{ij} d^*_j = \sum_j A_{ij} x^*_j = b_i = b'_{k+i} \quad \text{对后 } n \text{ 个约束}$$

故 $A'(d^*, s^*)^T = b'$。$\square$

**引理 5.4（反向：NIE 有解 ⇒ 0-1 IP 有解）**：若构造的 NIE 实例 $(A', b')$ 有解 $(d^*, s^*) \in \mathbb{N}^{2k}$ 使 $A'(d^*, s^*)^T = b'$，则原 0-1 IP 实例 $(A, b)$ 有解 $x^* \in \{0, 1\}^k$ 使 $Ax^* = b$。

**证明**：由 NIE 解的前 $k$ 个约束（0/1 编码约束）：
$$d^*_i + s^*_i = 1, \quad d^*_i, s^*_i \in \mathbb{N}$$

由引理 4.1，$d^*_i \in \{0, 1\}$。故 $d^* \in \{0, 1\}^k$。

由 NIE 解的后 $n$ 个约束（原约束迁移）：
$$\sum_j A_{ij} d^*_j = b_i, \quad i = 1, \ldots, n$$

即 $A d^* = b$。取 $x^* = d^*$，则 $x^* \in \{0, 1\}^k$ 且 $Ax^* = b$，故 $x^*$ 是 0-1 IP 的解。$\square$

**定理 B2b 的合成**：由引理 5.1（NIE ∈ NP）与引理 5.2-5.4（NIE 是 NP 困难的，且归约多项式），NIE 是 NP 完全的。$\square$

### 5.3 复杂度下界分析

**推论 5.1（最坏情况复杂度下界）**：若 $\text{P} \neq \text{NP}$，则 NIE 不存在多项式时间算法。

**证明**：由定理 B2b，NIE 是 NP 完全的。若 NIE 有多项式算法，则所有 NP 问题可多项式归约到 NIE 在多项式时间内求解，故 $\text{P} = \text{NP}$，矛盾。$\square$

**推论 5.2（Tenth shape 求解的最坏情况）**：Tenth 的护城河 B 若实现完整跨函数 shape 求解（即求解 NIE），在最坏情况下无多项式时间算法（除非 $\text{P} = \text{NP}$）。

**证明**：Tenth 的 shape 约束系统 $\Sigma(P)$ 可编码任意 NIE 实例（通过构造适当的 Tenth 程序，使 shape 变量对应 NIE 变量，约束对应 NIE 约束）。由定理 B2b，求解 $\Sigma(P)$ 是 NP 完全的。$\square$

**注 5.2（构造的具体性）**：推论 5.2 的"可编码任意 NIE 实例"需要构造性论证。给定 NIE 实例 $(A, b)$，可构造 Tenth 程序 $P_{A,b}$：
- 每个 NIE 变量 $d_j$ 对应 $P_{A,b}$ 中的一个 tensor 参数的某维度
- 每个 NIE 约束 $\sum_j a_{ij} d_j = c_i$ 通过精心设计的 `reshape`/`cat`/`split` 链路编码为 shape 等式

这一构造在原则上可行，但具体编码较为繁琐（涉及将线性组合映射到 shape 操作）。本文不给出完整构造，仅指出 NIE 的 NP 完全性是 Tenth shape 求解复杂度的合理下界参照。**此点的不严格性在 §9 局限中记录。**

## 6. 实践易解子类分析（开放猜想的实证研究）

> **本章节性声明**：本节包含的"易解子类"结论目前均为**猜想**而非定理。实证分析基于 `tenth/std/nn/` 的 shape 约束实例，但猜想的多项式可解性尚未严格证明。这是 §9 局限中重点披露的内容。

### 6.1 tenth/std/nn/ 的 shape 约束实例收集

我们考察 `tenth/std/nn/` 下的 13 个标准库文件，归纳实际出现的 shape 约束类型：

| 文件 | 主要约束类型 | 约束结构 |
|------|------------|---------|
| `linear.th` | `matmul` 内侧等式 + `transpose` 维度反转 | $K = K$，$[K, N] \to [N, K]$ 反转 |
| `attention.th` | `matmul` 链 + `transpose` | $D_k = D_k$，$[S_k, D_k] \to [D_k, S_k]$ 反转 |
| `multihead_attention.th` | `matmul` 链 + `reshape` (注释中 TODO) | $D_k = D_k$，$D_{\text{model}} / n_{\text{heads}} = D_k$（除法） |
| `feedforward.th` | 两层 `matmul` | $D = D$，$D_{\text{ff}} = D_{\text{ff}}$ |
| `conv.th` | `conv2d` 内部约束 | $C_{\text{in}} = C_{\text{in}}$，$kH, kW$ 已知 |
| `layer_norm.th` | 最后维归一化 | $D = D$ |
| `transformer.th` | 残差连接（加法 shape 兼容） | $[S, D] = [S, D]$ |
| `embedding.th` | 索引操作 | 通常无约束（索引不改变 shape） |
| `dropout.th` | shape 保持 | 无约束 |
| `activations.th` | shape 保持 | 无约束 |
| `batchnorm.th` | 通道维匹配 | $C = C$ |
| `positional_encoding.th` | 加法广播 | $[S, D] = [S, D]$ |
| `loss.th` | 交叉熵 shape | $[B, V]$ 与 $[B]$ 兼容 |

**实证观察**：

1. **二元等式约束占主导**：实际出现的约束几乎全是 $d_i = d_j$ 形式（两个 shape 变量相等），如 `matmul` 的 $K = K$、残差连接的 $[S, D] = [S, D]$。这类约束的系数矩阵每行至多两个非零元（$+1, -1$）。

2. **极少出现一般线性组合**：标准库中未出现 $a_1 d_1 + a_2 d_2 + \cdots = c$ 形式的约束（除了 `multihead_attention.th` 中的 $D_{\text{model}} / n_{\text{heads}} = D_k$，但这是除法且 $n_{\text{heads}}$ 是字面量，等价于 $D_{\text{model}} = n_{\text{heads}} \cdot D_k$，是乘法约束，不在本文线性等式范围内）。

3. **reshape 元素守恒多为已知值**：`reshape` 出现时，目标 shape 通常是字面量（如 `reshape(M*N)` 中 $M, N$ 已知），不建立符号方程，仅在运行时检查。

4. **跨函数约束链短**：实际函数调用链深度通常 $\leq 5$（如 `transformer.th` 调用 `multihead_attention` 调用 `scaled_dot_product_attention`），约束传播路径短。

### 6.2 约束矩阵的 Total Unimodularity 分析（猜想 C1）

**猜想 C1（TU 性质）**：Tenth 实际 shape 约束系统的系数矩阵 $A$ 是 total unimodular（TU）的。

**实证支撑**：由 §6.1 观察，实际约束矩阵 $A$ 的结构特征：
- 每行至多两个非零元（二元等式约束 $d_i = d_j$ 对应 $+1, -1$）
- 非零元取值于 $\{\pm 1\}$
- 每列的非零元分布稀疏

**已知 TU 判定条件**：
- **Ghouila-Houri 条件**：矩阵 $A$ 是 TU 的当且仅当其每行可被分为两类 $R_1, R_2$，使每列 $j$ 满足 $\sum_{i \in R_1} A_{ij} - \sum_{i \in R_2} A_{ij} \in \{0, \pm 1\}$
- **网络矩阵**：节点-边关联矩阵是 TU 的
- **区间矩阵**：每列连续非零元的矩阵是 TU 的

**部分论证尝试**：对二元等式约束矩阵，每行恰有两个非零元 $\pm 1$。这类矩阵与网络流问题的节点-边关联矩阵结构相似（每条边连接两个节点，关联矩阵中该列恰有两个 $\pm 1$）。若 Tenth 约束矩阵可解释为某图的关联矩阵，则由网络矩阵的 TU 性质（Tutte 1954）可得 TU。

**未完成的严格证明**：Tenth 约束矩阵与网络关联矩阵的对应关系需更细致论证：
- 网络关联矩阵的每列恰有两个非零元（一 $+1$ 一 $-1$，对应有向边的起点终点）
- Tenth 约束矩阵的每**行**恰有两个非零元（约束 $d_i - d_j = 0$ 对应 $+1$ 在 $i$ 列、$-1$ 在 $j$ 列）

行与列的角色不同，需考虑转置。事实上，节点-边关联矩阵的转置也是 TU 的（TU 在转置下不变），故 Tenth 约束矩阵（行=约束，列=变量）的转置对应"变量-约束"关联，结构上类似于"节点-边"关联。

**但**：网络关联矩阵的列对应"边"，每列恰两个非零元；而 Tenth 约束矩阵的**列**（对应变量）的非零元个数等于该变量参与的约束数，可能大于 2。例如若 $d_i$ 出现在 3 个约束中，则第 $i$ 列有 3 个非零元。这破坏了"每列两个非零元"的网络矩阵条件。

**改进方向**：Tenth 约束矩阵可能属于更广义的 TU 子类，如"每行至多两个非零元且每列至多 $k$ 个非零元"的 $k$-正则结构。这类矩阵的 TU 性质有更细致的判定条件（如 Conforti-Cornuéjols-Rao 分解），但本文未给出完整证明。

**猜想 C1 的状态**：基于实证观察与部分结构分析，**猜想** Tenth 实际 shape 约束矩阵具有 TU 性质，从而使对应 IP 多项式可解（Hoffman-Kruskal 定理：TU 矩阵的 IP 与 LP 松弛同解）。但**严格证明未完成**，TU 性质目前仅为猜想。

### 6.3 二元等式约束系统的 union-find 归约（猜想 C2）

**猜想 C2（union-find 多项式可解）**：若 Tenth shape 约束系统仅含二元等式约束 $d_i = d_j$ 与一元常量约束 $d_i = c$（$c \in \mathbb{N}$），则该系统在非负整数上多项式可解，时间复杂度近线性 $O(k \cdot \alpha(k))$，其中 $\alpha$ 是反 Ackermann 函数。

**归约思路**：将每个 shape 变量 $d_i$ 视为一个元素，约束 $d_i = d_j$ 视为 union 操作（合并 $d_i$ 与 $d_j$ 所在的等价类），约束 $d_i = c$ 视为给等价类赋常量值。

**算法**：
1. 初始化 union-find 结构，每个 $d_i$ 自成一类
2. 扫描所有二元等式约束 $d_i = d_j$，执行 `union(i, j)`
3. 扫描所有一元常量约束 $d_i = c$，将 $c$ 记录为 $d_i$ 所在等价类的"候选值"
4. 检查每个等价类的候选值集合：
   - 若候选值集合为空：等价类可取任意非负整数值（自由变量），可满足
   - 若候选值集合恰有一个值 $c$：等价类所有变量取值 $c$，可满足
   - 若候选值集合有多于一个值：约束矛盾，不可满足

**复杂度**：$n$ 个约束 + $k$ 个变量，union-find 操作总数 $O(n)$，每次操作 $O(\alpha(k))$（近似 $O(1)$）。总复杂度 $O(n \cdot \alpha(k))$。

**正确性论证（非形式化）**：
- 二元等式约束 $d_i = d_j$ 的传递闭包对应等价关系，union-find 准确计算等价类
- 一元常量约束 $d_i = c$ 限定整个等价类的取值
- 同一等价类内的多个常量约束若取值不同则矛盾

**未完成的形式化**：上述算法的正确性依赖于"二元等式约束的传递闭包与等价类赋值可同时求解"这一直觉。形式化证明需：
1. 归纳证明：union-find 计算的等价类与约束的等价闭包一致
2. 证明：等价类的可满足性等价于候选值集合的非矛盾性

这两步在标准 union-find 理论中已有定论（Tarjan 1975），但本文未给出针对 NIE 子类的完整形式化推导。**猜想 C2 的状态**：基于 union-find 的标准结果，**猜想**二元等式约束子类多项式可解，但严格证明留作未来工作。

### 6.4 Tenth 实际 shape 约束的精确复杂度

**猜想 C3（精确复杂度）**：Tenth 实际 shape 约束系统的精确复杂度为 $O(n \cdot \alpha(k) + k)$（近线性），而非一般 NIE 的 NP 完全。

**支撑证据**：
1. §6.1 的实证观察：实际约束以二元等式为主
2. 猜想 C1（TU 性质）：若成立，则 IP = LP，多项式可解
3. 猜想 C2（union-find）：若约束限于二元等式 + 一元常量，近线性可解

**反例可能性**：
- 若 Tenth 引入更复杂的 shape 约束（如 `reshape(M*N, K, L)` 要求 $M \cdot N = K \cdot L$，这是双线性约束，可能触发 NP 完全）
- 若跨函数传播深度极大（$> 1000$），即使每个约束是二元等式，union-find 仍近线性，但工程常数可能放大
- 若未来 Tenth 引入除法约束 $D_{\text{model}} / n_{\text{heads}} = D_k$ 并符号化（$n_{\text{heads}}$ 也是变量），则约束变为 $D_{\text{model}} = n_{\text{heads}} \cdot D_k$，是非线性，可能触发 NP 完全

**猜想 C3 的状态**：基于当前 Tenth 标准库的实证与猜想 C1、C2，**猜想** Tenth 实际 shape 约束的精确复杂度近线性。但此猜想：
1. 依赖于 C1（TU 性质）或 C2（union-find 子类）的成立
2. 仅适用于当前标准库的约束结构，未来扩展可能破坏
3. 未考虑用户代码中可能出现的复杂约束

**故护城河 B 的降级决策在理论层面是稳健的**：即使 C1/C2/C3 猜想成立，Tenth 也不能保证未来扩展不触发 NP 完全。超时保护作为"必需"而非"可选"是合理的工程决策。

| 理论结论（本文） | 工程影响（战略规划） |
|---------------|------------------|
| 定理 B2b：NIE 是 NP 完全的 | 完整 shape 求解无多项式时间算法保证 |
| 推论 5.2：Tenth shape 求解 NP 完全 | 编译期成本在最坏情况下不可预测 |
| §6 猜想 C1/C2/C3：实际易解子类 | 降级为 ⭐⭐⭐（非放弃）：实际场景可能易解，但需超时保护 |
| §5.3 注 5.2：构造的不严格性 | 降级决策不依赖精确下界，NP 完全上界已足够触发风险规避 |

两种情况下，降级为 ⭐⭐⭐ + 超时保护都是稳健决策。这是"理论下界 + 工程防御"组合的典型范例。

### 7.2 编译期-运行时边界划分原则

基于本文的理论结论，Tenth 的 shape 检查应遵循"检查多做、求解少做"的边界划分原则（战略规划 §方向 B）：

**编译期（默认开启，多项式时间）**：
- 等值匹配（$d_i = c$ 字面量检查）
- 二元等式约束（$d_i = d_j$，由 `check_method_shape`、`check_binary_shape_compat` 处理）
- 内存/算力预估（护城河 D，已实现）
- Autograd 反向 shape 验证（护城河 A，已实现）

这些操作在最坏情况下 $O(n \cdot \alpha(k))$ 或 $O(n \log n)$，不破坏自举 ~0.2s 保证。

**编译期（可选开启，需超时保护，可能 NP）**：
- 跨函数 shape 传播（护城河 B 完整版，`--strict-shapes` 模式）
- 一般线性等式约束求解
- 符号维度代数推理

这些操作可能触发 NP 完全，必须配合超时保护（建议 100ms）与回退到 `Any` 的降级路径。

**运行时（精确诊断，无复杂度风险）**：
- Tape 形式化根因分析（护城河 F，规划中）
- 运行时 shape 校验（已实现）

运行时分析看到的是已执行的 Tape，是精确事实而非预测，无复杂度风险（`形式化分析理论可行性论证.md` 定理 F5：$O(|V_{\text{reach}}| + |E_{\text{reach}}|)$）。

**分层架构的理论依据**：分层不是工程妥协，而是复杂度理论的必然要求。编译期只能做保守近似（定理 B1：精确分析不可判定；定理 B2b：保守近似的子类 NP 完全），运行时才能做精确分析。这是静态分析的本质局限（`形式化分析理论可行性论证.md` §6.8）。

## 8. 结论与未来工作

### 8.1 本文结论

本文针对 Tenth HIR shape 约束求解的复杂度下界进行了严格化分析，主要结论：

1. **定理 B2b 严格化**（§5）：给出 NIE 问题的完整双向归约证明（NP 成员 + NP 困难），归约构造基于松弛变量技巧 $d_i + s_i = 1$。归约的多项式性、正向正确性、反向正确性均严格论证。

2. **复杂度下界**（§5.3）：NIE 是 NP 完全的，Tenth shape 求解在最坏情况下无多项式算法（除非 P=NP）。

3. **战略降级的理论依据**（§7.1）：定理 B2b 直接解释护城河 B 从 ⭐⭐⭐⭐⭐ 降级为 ⭐⭐⭐ 的决策。降级的稳健性不依赖于易解子类猜想的成立。

4. **易解子类的实证猜想**（§6）：基于 `tenth/std/nn/` 的实例分析，提出三个猜想（C1: TU 性质；C2: union-find 多项式可解；C3: 精确复杂度近线性），均显式标注为未证明的开放问题。

5. **诚实记录局限**（§9）：归约构造的不严格处、猜想未完成证明、与工程实现的差距均显式披露。

## 9. 局限（诚实记录）

本文主动记录以下理论局限，遵循数理部"局限必披露"的底线要求。

### 9.1 归约构造的不严格性

**局限**：推论 5.2 的"任意 NIE 实例可编码为 Tenth 程序"未给出完整构造性论证。§5.3 注 5.2 承认"具体编码较为繁琐"，仅给出原则性论证。

**影响**：定理 B2b 本身严格（NIE 的 NP 完全性独立于 Tenth 实现），但"NIE 的 NP 完全性 ⇒ Tenth shape 求解 NP 完全"的推论 5.2 依赖未完成的构造。若构造不成立，Tenth shape 求解的精确复杂度可能优于 NP 完全（这正是 §6 猜想 C3 的来源）。

**缓解**：本文的工程结论（护城河 B 降级）不依赖推论 5.2 的严格性。NIE 作为 Tenth shape 求解的"合理上界参照"已足够触发风险规避决策。但理论严格性需补全。

**未来工作**：给出 NIE 到 Tenth 程序的完整构造编码，证明 Tenth shape 求解的精确下界。

### 9.2 易解子类猜想的未完成证明

**局限**：§6 的三个猜想（C1: TU 性质；C2: union-find 多项式可解；C3: 精确复杂度近线性）均未严格证明。

**具体未完成处**：
- C1：Tenth 约束矩阵与网络关联矩阵的结构对应关系未完整论证（§6.2 部分论证尝试）。每列非零元个数可能 > 2，破坏网络矩阵条件。
- C2：union-find 算法对 NIE 二元等式子类的正确性未形式化推导（§6.3 仅给出非形式化论证）。
- C3：依赖 C1 或 C2 的成立，本身无独立证明。

**影响**：§7.1 的"降级稳健性论证"不依赖这些猜想的成立，故工程决策不受影响。但理论层面，Tenth 实际 shape 约束的精确复杂度仍是开放问题。

**缓解**：所有猜想均显式标注为"猜想"而非"定理"，未误导读者。§6.4 的"反例可能性"明确列出可能破坏易解性的未来扩展。

**未来工作**：完成 C1/C2 的严格证明或构造反例。

### 9.3 实证分析的覆盖面局限

**局限**：§6.1 的实证分析仅考察 `tenth/std/nn/` 的 13 个文件，未覆盖：
- 用户代码中的 shape 约束（无可用样本）
- 自举编译器 `tenthc/` 的 shape 约束（待收集）
- 未来可能出现的复杂约束模式

**影响**：§6 的猜想基于有限样本，可能不具普遍代表性。

**缓解**：本文承认样本局限，猜想明确标注为"基于当前标准库的实证"。

**未来工作**：扩大样本范围，包括用户代码与自举编译器。

### 9.4 与工程实现的差距

**局限**：本文的形式化模型与 Tenth 实际实现存在差距：
- 形式化模型假设 shape 变量取值于 $\mathbb{N}$，但 Tenth 实现中 `Dim::Symbol` 不参与数值计算（仅同名等价），`Dim::Any` 表示完全未知
- 形式化模型假设约束可累积为全局系统，但 Tenth 实现的 `check_method_shape` 等是局部单点检查，不做全局传播
- 形式化模型的"跨函数约束传播"在 Tenth 当前实现中未启用（仅 `merge_return_shape` 做了有限的 shape 合并）

**影响**：本文的理论结论是针对"完整 shape 求解器"的复杂度，而非 Tenth 当前实现的复杂度。Tenth 当前实现实际上属于 §7.2 的"编译期多项式时间"类别（局部检查），不触发 NP 完全。

**缓解**：本文的工程影响分析（§7）明确区分"完整求解"与"局部检查"，未混淆两者。

**未来工作**：若 Tenth 实现完整 shape 求解器，需重新评估实际复杂度。

### 9.5 NP 完全性边界的解释谨慎

**局限**：NP 完全性是**最坏情况**复杂度，不代表**平均情况**或**实际场景**。本文 §6 的猜想正是针对平均/实际场景，但未严格证明。

**影响**：将"NP 完全"解释为"实际不可解"是过度解读。实际 shape 约束可能易解（若 C1/C2 成立）。

**缓解**：§7.1 明确区分"最坏情况 NP 完全"与"实际场景可能易解"，降级决策基于风险规避而非"实际不可解"判断。

**未来工作**：研究 Tenth shape 约束的平均情况复杂度（需定义约束分布）。

## 附录 C：实施建议

基于本文理论结论，对护城河 B 的实施提出以下建议：

1. **超时保护为必需**（定理 B2b）：建议 100ms，超过则跳过剩余检查。这是 NP 完全性的直接工程后果。
2. **限定约束子类**：实现二元等式约束（$d_i = d_j$）与一元常量约束（$d_i = c$）的求解（猜想 C2 的子类），不做一般线性等式。
3. **基于 union-find 实现约束求解**：若实施猜想 C2，可用 union-find 结构做近线性时间的二元等式求解。
4. **跨函数传播深度限制**：建议限制为 $\leq 10$ 层，防止恶意输入触发深度递归。
5. **诚实标注价值定位**：B 是"编译期预警"而非"精确求解"，对含递归/while 的函数保守标记 `Any`。
6. **未来扩展的复杂度监控**：若引入 `reshape(M*N, K, L)` 等非线性约束，需重新评估复杂度（可能触发双线性约束的 NP 完全）。
