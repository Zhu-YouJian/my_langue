## Phase 7: 核心标准库

### 目标

补齐自举编译器所需的所有标准库能力。核心数据结构在 Rust 侧实现为原生类型，上层通过解释器暴露给 Tenth 代码。

### Task 1: Vec\<T\> — 动态数组

**语法目标:**
```tenth
let mut tokens: Vec<Token> = Vec::new();
tokens.push(Token { kind: Int, value: 42 });
let first = tokens[0];
let len = tokens.len();
```

**实现：**
- Rust 侧实现 `NativeVec` 类型，基于 `Vec<Value>`
- 解释器新增 `Value::Vec` 变体
- 方法：`new()`, `push()`, `pop()`, `len()`, `is_empty()`, 索引读写 `a[i]`

### Task 2: String 方法

**语法目标:**
```tenth
let s: str = "hello";
s.len()          // => 5
s[0]             // => 'h'
s[1..3]          // => "el"
"a" + "b"        // => "ab"
```

**实现：**
- Rust 侧实现 `str` 的方法：`len`, 索引取字符, 切片, 拼接

### Task 3: HashMap\<K,V\> — 哈希表

**语法目标:**
```tenth
let mut map: HashMap<str, i32> = HashMap::new();
map.insert("x", 42);
let v = map.get("x");  // => Some(42)
```

**实现：**
- Rust 侧 `std::collections::HashMap<String, Value>` 封装

### Task 4: 文件 I/O

**语法目标:**
```tenth
let source = io::read_file("input.th");
io::write_file("output.c", c_code);
```

**实现：**
- Rust 侧 `std::fs::read_to_string` / `std::fs::write` 作为原生函数注册

### Task 5: Result / Option

**语法目标:**
```tenth
enum Option<T> { Some(T), None }
enum Result<T, E> { Ok(T), Err(E) }

let tokens = lexer.tokenize();
match tokens {
    Ok(ts) => println("success"),
    Err(e) => println("error"),
}
```

**实现：**
- 解释器预加载 `Option` / `Result` 枚举定义
- `try` 表达式支持（`let x = try fallible_fn();`）

## Phase 8: 自举编译器

### 目标

用 Tenth 重写编译器核心管线，Rust 编译器作为 bootstrap 驱动。

### 编译器结构（Tenth 实现）

```
tenthc/                    # 自举编译器源码 (Tenth)
├── main.th               # 入口：compile(input, output)
├── lexer/
│   ├── token.th          # TokenKind 枚举
│   └── lexer.th          # Lexer: new(source) → tokenize() → Vec<Token>
├── parser/
│   ├── ast.th            # AST 节点（Expr, Stmt, Item, Program）
│   └── parser.th         # Parser: new(tokens) → parse() → Program
├── hir/
│   ├── types.th          # Type 定义
│   └── lower.th          # AST → HIR + 类型检查
├── codegen/
│   └── cgen.th           # HIR → C 代码生成
└── std/                  # 标准库 (Vec, HashMap, io, Result)
```

### Task 6: Token + Lexer（Tenth 实现）

- [ ] 定义 `TokenKind` 枚举（全部 60+ token 种类）
- [ ] 实现 `Lexer::new(source: str)` → 字符遍历 → `tokenize()` → `Vec<Token>`
- [ ] 测试：与 Rust 版 Lexer 对同一输入输出一致

### Task 7: Parser（Tenth 实现）

- [ ] 定义 AST 节点（Expr, Stmt, Item, Program）

### Task 8: HIR Lowering + Type Check（Tenth 实现）

- [ ] 定义 HIR 类型
- [ ] 实现 AST → HIR 降级 + 类型推断 + 借用检查

### Task 9: C Codegen（Tenth 实现）

- [ ] 实现 HIR → C 代码生成

### Task 10: Bootstrap — Rust 编译器编译 Tenth 编译器

```bash
# 用 Rust 版编译器编译 Tenth 版编译器
cargo run -- compile tenthc/main.th -o tenthc.c
gcc tenthc.c -o tenthc.exe

# 用 Tenth 编译器编译自身（自举循环！）
./tenthc.exe compile tenthc/main.th -o tenthc_v2.c
gcc tenthc_v2.c -o tenthc_v2.exe

# 验证：两次生成的 C 代码一致
diff tenthc.c tenthc_v2.c
```

- [ ] Rust 编译器成功生成 `tenthc.c`
- [ ] gcc 成功编译出 `tenthc.exe`
- [ ] `tenthc` 能编译自身，且输出与上一代一致
