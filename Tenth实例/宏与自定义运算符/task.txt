# 宏与自定义运算符

重点演示 Tenth "新语言"味道最浓的两个元编程特性（M3.1 / M3.3，2026-08-02）。

## 文件

- `macro_ops.th` — 声明式宏 + 自定义运算符 专题演示（默认 VM 路径即可）
- `operator_overload.th` — struct 上的运算符重载（`impl Add` → `a + b` 降级为 `a.add(b)`），因 VM 对具体值 trait 方法分派有缺口，需解释器路径：`TENTH_NO_VM=1 tenth run operator_overload.th`

## 覆盖

**声明式宏**（编译期展开为普通 AST，与手写代码等价）：
- 基础展开 `twice(x) { x + x }`
- 宏嵌套调用（宏体内调用其他宏）
- 0 参宏、实参重复使用（无 hygiene，C 宏风格）
- 宏体为任意表达式（if 表达式）
- 宏在函数/循环中调用
- 宏 + 自定义运算符组合

**自定义运算符**：
- 字符集 `@` `$` `~` 连续组合（`@@`、`@~`、`$$`、`$@`、`~~`、`@$@`）
- 声明语法 `operator <op> = fn(a, b) -> R { ... }`
- 优先级统一与 `+`/`-` 同级（4，左结合），低于 `*`/`/`/`%`
- 绑定函数合成名 `__custom_op_<op>`（含运算符字符，经普通函数间接调用）
- 与内置运算符、宏自由组合

## 运行

```
tenth run macro_ops.th
TENTH_NO_VM=1 tenth run operator_overload.th
```

宏展开在 parse 阶段、自定义运算符降级为普通函数调用，默认 VM/JIT 路径原生支持，无需 TENTH_NO_VM。
